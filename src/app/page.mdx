# 🤖 AI Agents 2026 — 交互式学习课程

> 面向资深开发者的 AI Agent 架构学习课程。概念驱动，不教框架 API。

## 为什么做这个课程？

现有的 AI Agent 课程要么太基础（面向初学者），要么太碎片化（无系统路径），要么太长（谁有时间看 10 小时视频？）。

这个课程不同：
- **概念驱动** — 教的是底层模式（状态机、记忆架构、工具编排），不是某个框架的 API
- **精炼** — 每个模块 ~30 分钟，2000-3000 字，配比喻和代码片段
- **交互可视化** — 核心模块有 React Flow 交互演示（开发中）
- **面向资深开发者** — 跳过基础概念，直击 Agent 范式中真正新的东西

## 7 个模块

| 模块 | 主题 | 核心比喻 |
|------|------|---------|
| [1. Context Engineering](/modules/module-1-context-engineering) | 上下文窗口管理、RAG 进阶 | 工作台 — 有限空间，战略摆放 |
| [2. Memory Architecture](/modules/module-2-memory-architecture) | 短期/长期/情景记忆 | 人类记忆模型 — 工作记忆、长期存储 |
| [3. Tools & MCP](/modules/module-3-tools-and-mcp) | 函数调用、MCP 协议 | 工匠与工具，MCP 是万能适配器 |
| [4. Reasoning & Planning](/modules/module-4-reasoning-and-planning) | ReAct 循环、任务分解 | 侦探破案 — 假设、调查、证据、修正 |
| [5. Pipeline Orchestrator](/modules/module-5-pipeline-orchestrator) | 状态机、事件驱动管道 | 电影导演 + 制作流水线 |
| [6. Multi-Agent Systems](/modules/module-6-multi-agent-systems) | 多 Agent 协作、动态编排 | 手术团队 — 各有专长，协调配合 |
| [7. Production Essentials](/modules/module-7-production-essentials) | Guardrails、可观测性、评估 | 任务控制中心 — 监控、告警、手动覆盖 |

## 学习路径建议

**快速入门：** 先看 Module 4（推理与规划），这是 Agent 最核心的能力。

**系统学习：** 按顺序 1 → 7，每个模块建立在前一个的基础上。

**按需查阅：** 每个模块独立成篇，可以直接跳到你关心的主题。
